# Legacy turn attribution

A conversation turn's stored `source` can contain its owner/actor label. The public source contract comes from RHC `conversationSourceForScope(true)` / `selectedSessionTurns`: metadata.nativeCli, then metadata.source, then a stored source different from session_owner, then an owner proven by same-organization/workspace/session events. A source-selected read accepts unattributed turns only when no other event provider exists in that same scope.

The pure SQL helpers in src/shared/legacy-turn-source.ts implement this contract for source discovery/export and the readonly analysis projection. Discovery resolves a missing tag only from one proven event provider in that workspace. A truly untagged turn-only scope stays explicit `legacy_source_unbound` coverage RED. No actor label, empty string or default harness becomes an inferred provider. The empty discovery sentinel is rejected before a source unit is admitted; it exists only to keep keyset paging from hiding NULL scopes.

Legacy export filters rows through that public attribution predicate and normalizes the private canonical row.source to the admitted harness. It preserves the original column as legacy_stored_source, along with all original IDs, content, owner, metadata, actor fields and microsecond timestamps. The public turn tuple uses turn_index, workspace_id, original stored source, id. comparePublicTurnRows and canonicalLegacy preserve that ordering; the Node page materializer must consume the same comparator/private field before publication.

The SQL parity oracle is generated from exact RHC27754aa15a805aa9878707dcfaaa48daf74be3aacfc, the selected_session_turn_ids function matching the public helper. Regenerate/check offline with scripts/update-public-turn-oracle.ts <RHC checkout> <exact SHA> [--check]; the fixture records repository/path/SHA and function hash. Tests run the actual oracle and helper in PGlite, including owner-equals-source, metadata overriding stored source, unique event fallback, tenant/workspace isolation, unbound scopes and reversed-UUID ordering.

Shared helper/parser/materializer composition and all current legacy source shapes still need independent review and exact-head CI. No production query, schema/credential/flag change, data cleanup or deployment is performed here.
